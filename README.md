# Exercícios de Bancos de Dados NoSQL

Repositório com códigos e registros das atividades práticas da disciplina de Bancos de Dados NoSQL. Os exercícios executados no Ubuntu Server estão documentados em PDFs com comandos e capturas de tela; os projetos em Python estão nas pastas próprias.

## Conteúdo

| Pasta | Atividade | Material |
| --- | --- | --- |
| [`openf1/`](./openf1/) | Coleta dados da API OpenF1 e armazena sessões, pilotos e voltas no MongoDB. | Código Python |
| [`openf102/`](./openf102/) | Aplicação Streamlit para explorar os dados da OpenF1 armazenados no MongoDB. | Código Python |
| [`dados_cartola/`](./dados_cartola/) | Coleta e armazenamento de dados do Cartola FC no MongoDB. | Código Python |
| [`georeferenciamento_mongo/`](./georeferenciamento_mongo/) | Materiais de georreferenciamento com MongoDB. | Pasta do exercício |
| [`slideEx01/`](./slideEx01/slide01atividade.pdf) | Atividade 1: importação e consultas de restaurantes no MongoDB, executada no Ubuntu Server. | PDF com registros da execução |
| [`slideEx02RIAK/`](./slideEx02RIAK/RIAK.pdf) | Atividade 2: operações com buckets e chaves no Riak, executada no Ubuntu Server. | PDF com registros da execução |
| [`redis/`](./redis/Lista%20REDIS.pdf) | Lista de exercícios de Redis, executada no Ubuntu Server. | PDF com registros da execução |

## Projeto GeoLog

O projeto de georreferenciamento com **Persistencia poliglota e GeoJSON** está em um repositório separado: [trabalho_nosql_p4 — GeoLog](https://github.com/DaviDantass/trabalho_nosql_p4).

## Ambientes

- **Ubuntu Server:** atividades práticas de MongoDB, Riak e Redis registradas nos PDFs.
- **Windows:** desenvolvimento dos projetos em Python e da aplicação Streamlit.
